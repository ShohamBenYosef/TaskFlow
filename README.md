# TaskFlow

TaskFlow is a simple task management application written in C++.

The project was built to practice OOP concepts like inheritance, polymorphism, abstract classes, smart pointers, and file persistence.

## Features

- Basic tasks
- Deadline tasks
- Recurring tasks
- Mark tasks as completed
- Save tasks to a file
- Load tasks from a file

## Technologies

- C++
- STL
- Smart Pointers
- CMake

## Build

```bash
cmake -S . -B build
cmake --build build
./build/TaskFlow
